Rules

The bundled Emerging Threats tarball is ET Open for Suricata 5 (feed 9840, Sept 2021). Do not convert those files. Pull a current Suricata 8 ruleset:

sudo /var/packages/ThreatPrevention/scripts/update-rules.sh
sudo synopkg restart ThreatPrevention

Default source is ET Open. Optional extras after update-sources: Abuse.ch SSLBL, ET Pro (license), etc.
