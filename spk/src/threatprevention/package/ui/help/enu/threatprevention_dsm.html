Threat Prevention on this NAS

This package runs vanilla Suricata 8 on DSM 7 x86_64 and drives the official Threat Prevention window. It is a research PoC: IDS only. It does not drop packets (no NFQUEUE / IPS).

Note:

  • This NAS is not the network gateway. Listening on LAN interfaces sees only traffic to or from the NAS unless you enable a router traffic copy. See Router traffic copy in this help set.
  • The Prevention / drop-packet options in Settings are stored but not enforced. Official Settings help still describes SRM IPS; ignore those drop-packet steps on this NAS.
  • Unsigned packages cannot declare file capabilities. After every install or upgrade, an administrator must apply setcap on bin/suricata or capture fails to start.
  • After UI-affecting upgrades, log out of DSM and log in again so the Start Menu reloads the app script.

After install

  1. SSH to the NAS as an administrator.
  2. Apply capabilities on the new Suricata binary (DSM replaces it on every install):

    /usr/bin/setcap cap_net_raw,cap_net_admin,cap_ipc_lock+ep /var/packages/ThreatPrevention/target/bin/suricata

  3. Start or restart the package: synopkg restart ThreatPrevention (use /usr/syno/bin/synopkg if synopkg is not on PATH).
  4. Confirm getcap …/target/bin/suricata lists those capabilities and that suricata.log contains Engine started.

Capture source

In Settings > General:

  • Listen on NAS LAN interfaces — Suricata listens on the NAS interfaces (typically the OVS LAN bridge ovs_eth0). Only traffic to or from this NAS is inspected.
  • Receive a traffic copy from the router — OpenWrt GRE-copies or MikroTik TZSP-copies LAN↔WAN onto local tps0. Enter the router LAN IPv4 and pick OpenWrt or MikroTik. Allow GRE (protocol 47) or UDP 37008 from that router in DSM Firewall. Apply, then restart this package so the tap is created. Full steps: Router traffic copy.

Monitored Interfaces should show one enabled capture device. In copy mode that is tps0, not tps0 plus LAN 1.

Signature updates

Use Update Now or the automatic schedule. The first download of ET Open can take several minutes. When it finishes, last-updated is stamped and status becomes up to date. Connection errors mean the NAS could not reach Emerging Threats.

Events, policy, and notifications

  • Overview / Events / Statistics — alerts from Suricata eve.json.
  • Self-Defined Policy — enable or disable signature classes; changes compile into suricata.rules and reload the engine.
  • Notification — DSM mail/push plus optional Telegram (this PoC).
